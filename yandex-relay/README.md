# Сервер онлайн-игр в Яндекс Облаке

Онлайн-режим дурака, шахмат, нард и морского боя по умолчанию работает через зарубежные бесплатные сервисы (PeerJS, MQTT). Из России к ним часто не подключиться без VPN. Этот маленький сервер в Яндекс Облаке пересылает ходы между игроками и работает без VPN.

**Как устроено:** игрок ⇄ **API Gateway** (WebSocket) → **Cloud Functions** (`index.js`) → другой игрок.
В **Object Storage** хранится только «код комнаты → соединение хозяина». Сами игры по-прежнему считает браузер хозяина комнаты.

**Сколько стоит:** при игре с друзьями — укладывается в бесплатные лимиты:
- Cloud Functions: 1 000 000 вызовов в месяц бесплатно;
- Object Storage: 10 000 записей и 100 000 чтений в месяц бесплатно, удаление бесплатно;
- WebSocket в API Gateway сейчас в стадии Preview и не тарифицируется (сообщения игрокам и пинги не тарифицируются).

Для работы облака нужен платёжный аккаунт с привязанной картой. Деньги списываются, только если превысить бесплатные лимиты.

---

## Шаг 1. Аккаунт и каталог

1. Откройте [console.yandex.cloud](https://console.yandex.cloud) и войдите с аккаунтом Яндекса.
2. Создайте **платёжный аккаунт** (привяжите карту). Новым пользователям обычно дают стартовый грант.
3. Будет создано облако с каталогом `default` — дальше всё делаем в нём.

## Шаг 2. Сервисный аккаунт

От его имени функция работает с хранилищем и отправляет сообщения игрокам.

1. В каталоге откройте **Identity and Access Management** → **Сервисные аккаунты** → **Создать сервисный аккаунт**.
2. Имя: `casino-relay`.
3. Добавьте роли:
   - `functions.functionInvoker` — чтобы API Gateway мог вызывать функцию;
   - `api-gateway.websocketWriter` — чтобы функция могла отправлять сообщения игрокам;
   - `storage.editor` — чтобы функция могла читать и записывать комнаты в бакет.
4. Нажмите **Создать** и скопируйте **ID** аккаунта (вида `aje…`).

## Шаг 3. Бакет Object Storage

1. Откройте **Object Storage** → **Создать бакет**.
2. Имя: любое уникальное, например `casino-rooms-12345` (запомните его).
3. Доступ на чтение объектов и к списку объектов: **ограниченный** (бакет приватный).
4. Максимальный размер: 1 ГБ, класс хранилища: стандартное. **Создать бакет**.
5. (Необязательно, для порядка) В настройках бакета → **Жизненный цикл** → добавьте правило: удалять объекты через 1 день.

## Шаг 4. Функция

1. Откройте **Cloud Functions** → **Создать функцию**, имя `casino-relay`.
2. Выберите среду выполнения **Node.js** (версия 18 или новее) и отключите «Добавить файлы с примерами кода».
3. Способ: **Редактор кода**. Создайте файл `index.js` и вставьте в него содержимое файла [`index.js`](index.js) из этой папки.
4. Параметры:
   - Точка входа: `index.handler`
   - Таймаут: `10` секунд
   - Память: `128` МБ
   - Сервисный аккаунт: `casino-relay`
   - Переменные окружения: ключ `BUCKET`, значение — имя бакета из шага 3.
5. Нажмите **Сохранить изменения**. Скопируйте **ID функции** (вида `d4e…`) на странице «Обзор».

## Шаг 5. API Gateway

1. Откройте **API Gateway** → **Создать API-шлюз**, имя `casino-ws`.
2. В поле **Спецификация** вставьте содержимое файла [`gateway.yaml`](gateway.yaml), заменив:
   - `ВСТАВЬТЕ_ID_ФУНКЦИИ` — на ID функции из шага 4 (в трёх местах);
   - `ВСТАВЬТЕ_ID_СЕРВИСНОГО_АККАУНТА` — на ID сервисного аккаунта из шага 2 (в трёх местах).
3. Нажмите **Создать**.
4. На странице шлюза скопируйте **Служебный домен** — вида `d5dxxxxxxxxxxxxxxxxx.apigw.yandexcloud.net`.

## Шаг 6. Подключить сайт

Адрес сервера игр: `wss://<служебный домен>/ws`, например `wss://d5dxxxxxxxxxxxxxxxxx.apigw.yandexcloud.net/ws`.

Пришлите его Claude — он впишет его в `js/net-config.js`. Или впишите сами:

```js
window.CASINO_NET = {
  relay: 'wss://d5dxxxxxxxxxxxxxxxxx.apigw.yandexcloud.net/ws',
};
```

После слияния изменений на сайте:
1. Откройте на сайте любую онлайн-игру → **Создать онлайн-комнату**. Под кодом должно появиться «✅ Сервер игр подключён — друзья смогут войти без VPN».
2. Друг вводит код на своём телефоне без VPN — должно появиться «Подключено через сервер игр».

## Если что-то не работает

- **Нет надписи «✅ Сервер игр подключён»** — проверьте адрес в `js/net-config.js` (начинается с `wss://`, заканчивается на `/ws`) и спецификацию шлюза (ID функции и сервисного аккаунта).
- **Подключение есть, но «Комната не найдена» или ходы не доходят** — откройте функцию → **Логи**. Ошибки `storage … 403` означают, что у сервисного аккаунта нет роли `storage.editor` или неверное имя бакета в `BUCKET`; ошибки при отправке сообщений — нет роли `api-gateway.websocketWriter`.
- Соединение WebSocket в Яндекс Облаке живёт до 60 минут — игра переподключается автоматически, партия продолжается.
- Если сервер игр недоступен, игра сама переключится на запасные каналы (PeerJS, MQTT), как раньше.
