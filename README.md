# 🎰 Мини-казино

Браузерное казино на виртуальные деньги (старт — 50 000 ₽). Без сборки и зависимостей: откройте `index.html`.

## Игры
| Вкладка | Файл | Описание |
|---|---|---|
| 🍒 Слоты | `js/slots.js` | 5×3, 10 линий, дикий, фриспины, бонус «Сундуки», риск-игра |
| ⚡ Олимп | `js/olympus.js` | 6×5, платит везде, тумбл, шары множителей, ante, покупка бонуса |
| 🍬 Sweet | `js/sweet.js` | в стиле Sweet Bonanza: платит везде (8+), тумбл, бомбы-множители во фриспинах, ante, покупка бонуса |
| 📖 Египет | `js/egypt.js` | в стиле Book of Ra: книга — дикий и скаттер, расширяющийся символ во фриспинах |
| 🎣 Big Bass | `js/bigbass.js` | в стиле Big Bass Bonanza: рыбак собирает денежных рыб, фриспины с уровнями |
| 🐕 Dog House | `js/doghouse.js` | в стиле Dog House Megaways: до 117 649 способов, тумбл, липкие дикие с множителями |
| 🤠 Hold & Win | `js/holdwin.js` | в стиле Money Train: 6+ монет — респины с фиксацией, джекпоты MINI…GRAND |
| 🗿 Эльдорадо | `js/avalanche.js` | в стиле Gonzo's Quest: лавины и растущий множитель, Free Falls |
| 📜 Наследие | `js/legacy.js` | в стиле Legacy of Dead: каждый ретриггер добавляет расширяющийся символ |
| 🎡 Рулетка | `js/roulette.js` | европейская рулетка |
| 🃏 Блэкджек | `js/blackjack.js` | взять / стоп / удвоить, блэкджек 3:2 |
| 🎴 Баккара | `js/baccarat.js` | Игрок / Банкир / Ничья, стандартные правила третьей карты |
| 🎲 Кости | `js/sicbo.js` | Sic Bo на трёх кубиках |
| 🚀 Ракета | `js/crash.js` | Crash с авто-выводом, RTP ≈ 96% |
| 🔻 Плинко | `js/plinko.js` | 8/12/16 рядов, три уровня риска |
| 💣 Мины | `js/mines.js` | поле 5×5, 1–24 мин, вовремя заберите выигрыш |
| 🎟️ Скретч-карты | `js/scratch.js` | сотрите слой, три одинаковые суммы — выигрыш |
| 🎲 Кубики | `js/dice.js` | число 0–99.99, «больше/меньше» порога, RTP 98% |
| 🎯 Колесо фортуны | `js/wheel.js` | множитель сектора применяется к ставке, три уровня риска |

Каталог игр (карточки, поиск, категории, «Недавние») — `js/catalog.js`; прямая ссылка на игру: `…/Homework/#crash`.
Общий код (баланс, навигация, карты) — `js/core.js`, векторные символы — `js/art.js`, анимации и эффект BIG WIN — `js/anim.js`, общий интерфейс линейных слотов — `js/slotui.js`, стили — `css/style.css`.

## Публикация на GitHub Pages
Репозиторий → Settings → Pages → Source: **GitHub Actions**. После слияния в `master` (или `main`) workflow `.github/workflows/pages.yml` опубликует сайт.
