# 🎰 Мини-казино

Браузерное казино на виртуальные деньги (старт — 500 000 ₽). Без сборки и зависимостей: откройте `index.html`.

Общий код (баланс, навигация, карты) — `js/core.js`, векторные символы — `js/art.js`, анимации и эффект BIG WIN — `js/anim.js`, общий интерфейс линейных слотов и автоигра с настройками — `js/slotui.js`, ставки −/+/MAX, турбо и пробел — `js/slotextras.js`, выбор фриспинов, покупка бонуса и супер-бонуса, интрига на барабанах и прогрессивный джекпот — `js/slotfx.js`, лобби и онлайн-комнаты для игр на двоих — `js/duel.js`, стили — `css/style.css`.

## Публикация на GitHub Pages
Репозиторий → Settings → Pages → Source: **GitHub Actions**. После слияния в `master` (или `main`) workflow `.github/workflows/pages.yml` опубликует сайт.
